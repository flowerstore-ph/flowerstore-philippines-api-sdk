## 📌 Overview

This repository provides software developers, e-commerce platforms, and logistics partners with open data structures, API reference schemas, and code samples for integrating same-day flower, cake, and gift delivery into custom applications across Metro Manila, Metro Cebu, Metro Davao, and provincial Philippines.

* **Official Website:** [https://flowerstore.ph](https://flowerstore.ph)
* **Primary Coverage:** Metro Manila (Same-Day Express), Metro Cebu, Metro Davao, Cavite, Laguna, Rizal, Bulacan.
* **Supported Categories:** Bouquet Flowers (Roses, Sunflowers, Tulips, Orchids), Chocolates, Cakes, Personalized Gifts, Funeral/Sympathy Standees, Grand Opening Stands.
